# EVA Project Page

English project page for **EVA: Evidence-seeking Visual Agent for
Hallucination-Resistant Multimodal Reasoning** (NeurIPS 2026).

Ting Lei, Yu Chen, Yang Liu. Wangxuan Institute of Computer Technology,
Peking University.

- Project page: https://ltttpku.github.io/EVA-page/
- Repository: https://github.com/ltttpku/EVA-page
- Code: https://github.com/oceanflowlab/EVA

## Preview

Open `index.html` in a browser. No build step, package installation, or external
CDN is required. The figures and Lucide icons are served locally.

## Publish

Push to `main`. In GitHub Settings > Pages, select **Deploy from a branch**,
**main**, and **/(root)**. The `.nojekyll` file enables ordinary static hosting.

## Content

The benchmark table follows Table 1 of the authors' public November 3 paper,
included at `assets/paper.pdf`. The efficiency and ablation values follow the
same paper. Project figures are reproduced from the authors' materials without
modification. The anonymous submission PDF and the Chinese press document
are not distributed by this website.

Update `index.html`, `styles.css`, and `app.js` to edit the page. Benchmark rows
for both backbones are in `app.js`; the default Qwen table is also present in
the HTML for visitors without JavaScript. The Paper resource link opens the
public PDF supplied by the authors.

EVA-authored page code: Apache-2.0. Lucide icons retain the license in
`assets/icons/LICENSE`. Paper figures remain the authors' research materials.
